# con.co — Luxury Travel & Adventure Booking Website

A modern, responsive landing page and web application for curated global expeditions, boutique journeys, and travel adventures.

---

## ✨ Features

- **Responsive Grid & Flexbox Layout**: Clean layout optimized across mobile, tablet, laptop, and ultra-wide displays.
- **Glassmorphic Navigation**: Sticky blurred header with smooth section scrolling and interactive mobile drawer menu.
- **Hero Section**:
  - Floating badges (*24/7 Guide Support*, *Live Rating*, *Request a Call*).
  - Social proof traveler avatar stack.
  - Performance statistics counter.
- **Featured Destinations**:
  - Interactive destination cards (Rome, California, Zurich, Santorini).
  - Price tags, location indicators, and hover animations.
- **Why Choose Us**: Key service highlights with custom SVGs and clean typography.
- **Trip Documentations & Video Modal**:
  - Cinematic documentary banner with pulsing play trigger.
  - Lightweight modal player.
- **Customer Testimonials**: Social proof cards featuring authentic quotes and rating stars.
- **Interactive Newsletter**: Subscription form with instant feedback toast alerts.
- **Toast Notification System**: Custom notification toasts for actions and form submissions.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic markup, accessible labels, and SEO meta tags.
- **CSS3**: Custom CSS variables, CSS Grid, Flexbox, glassmorphism, and micro-animations.
- **Vanilla JavaScript**: Lightweight event handling, modal triggers, toast notifications, and mobile navigation.
- **Font Awesome 6**: Vector icons.
- **Google Fonts**: *Plus Jakarta Sans* & *Ubuntu*.

## 🚀 Getting Started

### Run with Python:
```bash
python -m http.server 3000
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Run with Node.js / npx:
```bash
npx serve .
```
